# Urban Infrastructure AI Monitoring & Self-Healing System

AI-driven system for **predictive monitoring and resilience analysis of urban infrastructure networks**.

## Features

• Flood-induced cascade failure simulation
• Machine learning models for failure prediction
• Graph-based infrastructure modeling
• Repair optimization strategies
• Smart-city monitoring dashboard

## System Architecture

Infrastructure Network →
Flood Risk Simulation →
Cascade Failure Model →
AI Prediction →
Repair Optimization →
Self-Healing Recommendations

## Tech Stack

Python
Django Dashboard
NetworkX
Machine Learning
GIS Data Processing

## Dashboard

The system includes an interactive dashboard showing:

* Cascade failure simulation
* Infrastructure risk metrics
* Repair optimization results
* Self-healing recommendations

## Running the Project

```bash
python run_scenario.py
cd infra_ai_system
python manage.py runserver
```

Then open:

```
http://127.0.0.1:8000
```

## Note

Datasets are not included in this repository due to GitHub size limits.
Place required datasets inside the `data/` directory.
